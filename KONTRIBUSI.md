## KONTRIBUSI

Saat ini hanya menerima kontribusi untuk penggunaan Agentic AI karena berpacu dengan waktu, agar mudah dan cepat pengembangannya. hehe. (-alasan)

Bagaimana cara kontribusi?

- Fork repository ini
- Clone repositiry yang sudah di fork ke komputer/laptop
- Edit dan tambahkan baris tugas pada `TASKS.md`

## TASKS.md

- Misal menambahkan fitur
- Buat judul dan daftar/list tugas dibaris paling bawah

Contoh format:

```
## Fitur: Opsi Keperluan

- Tambahkan form opsi Keperluan: Menjemput Siswa, Kegiatan Workshop, ...
- Layout:
  - Posisi form opsi disimpan dibawah Hasil pindai
- Ukuran form opsi besar dan rapih
```

## Commit perubahan ke Github

- Buat branch baru misal: `deni`
- Pindah ke branch `deni`
- Commit perubahan
- Push ke github
- Buka repositiry `github.com/deni/eguestbook` 
- Klik tombol `Create pull request`
- Pastikan tidak ada conflict/**Able to merge** 
- Merge pull request
